# StudyFlow AI 🚀

StudyFlow AI is a full-stack AI-powered study platform built using the MERN stack and Generative AI technologies. The platform helps students improve productivity and learning efficiency through AI-powered PDF summarization, Chat-with-PDF conversations, AI quiz generation, smart notes management, and a modern responsive dashboard.

The project integrates OpenRouter API for Large Language Model (LLM) based AI functionalities and provides a modern SaaS-style user experience with secure authentication and responsive UI design.

- Persistent login using local storage
